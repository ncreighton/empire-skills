# empire-skills-mcp

An MCP server exposing the Empire executable agent skills as tools — deterministic, offline, no API keys.

## Install

```
pip install empire-skills-mcp
```

## Run (stdio)

```
empire-skills-mcp
```

Add to any MCP client as a stdio server running `empire-skills-mcp`.
