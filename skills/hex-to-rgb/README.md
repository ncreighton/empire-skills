# hex-to-rgb

> Use this skill to convert a hex color (#rrggbb or #rgb) to RGB values and a css rgb() string. Deterministic, offline.

`v0.1.0` `tool` `cost: free`

## Install

**Claude Code / any skills.sh-compatible agent:**
```bash
npx skills add <owner>/hex-to-rgb
```

**As an MCP tool:** point your MCP client at the bundled `mcp_tool.json`, or install via the MCP registry entry.

## Usage

```bash
python run.py --hex <string>
```

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `hex` | string | yes | Hex color, e.g. #1a2b3c |
